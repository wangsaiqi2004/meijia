# Nail Note release 2026-11-16

This release includes the previously uncommitted administrator pricing feature:
four editable point prices, default-price reset, and transactional configuration
audit records. Reservations read prices inside the balance transaction, and
refunds use the amount recorded on the original generation.

Review fixes:

- Database failures and invalid stored prices stop reservations instead of
  silently substituting default prices. Administrators can repair invalid rows.
- Shop responses resolve prices and their source together. The workbench
  refreshes prices before submission and requires another click after a change.
- A failed status read after a successful submission keeps tracking the accepted
  task. Polling requests do not overlap or update a replaced task.
- Repeat generation sends the selected resolution so displayed and charged
  prices agree.
- Task expiry uses the worker start time and a three-minute timeout, with the
  expiry condition rechecked when refunding.
- Redeem-code creation uses the administrator action lock.
- The test runner always creates an isolated temporary database instead of
  migrating or clearing the caller's DATABASE_URL.
- Linux startup scripts retain LF line endings. Image builds run the nail tests.
- Next.js and sharp are updated to 16.4.6 and 0.35.5 to include published security
  fixes affecting the older server and image-processing dependencies.
- Prisma remains on version 6; its configuration dependencies receive scoped
  overrides for the patched deepmerge-ts and effect versions.

Validation: 26 automated tests, TypeScript checks, and desktop/mobile browser
checks covering pricing save/reset, rejected invalid prices, owner access
restrictions, status-request interruption, single submission, and repeat 4K
billing. Browser generation uses a mock provider in an isolated local database.

Deployment requires an online SQLite backup and a separate test startup against
a production database snapshot before changing the application image. The
migration only adds SystemConfig and ConfigAudit. Image rollback leaves business
data and these additive tables in place.
