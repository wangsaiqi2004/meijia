# Nail Note 界面整理

日期：2026-11-05

## 设计方向

- 产品：美甲师使用顾客手部照片和款式参考图，预览上手效果并沟通细节。
- 性格：安静、细致、务实。
- 场景：美甲工作台、甲片色卡和自然光。
- 视觉重点：款式照片和顾客的上手效果；导航与表单使用中性灰。
- 识别细节：01–04 的工序编号，沿用已有深绿色作为操作与选中状态。

## 原界面问题

- 登录页：抽象圆环、大面积深绿色、英文大写标签与宽字距。
- 工作台：多个相近的绿色文字、过小的说明文字和嵌套的分区边框。
- 工作台主操作：闪光图标强调生成技术，款式图悬停缩放。
- 共用页面：大写的装饰性副标题、多个字号与字重、半透明的手机导航。

## 改动

1. 间距：统一分组间距，侧栏导航使用 36px 行高；工作台四个步骤使用连续分区。
2. 颜色：页面、边框与三个文字层级统一为中性色，保留深绿色操作色。
3. 图标：沿用 Lucide，统一线宽，移除闪光图标与不必要的图标底块。
4. 文案：使用“试一款美甲”“补充要求”“上手效果”等具体标题，去掉装饰性英文标签。
5. 字体：主要使用 400、500 字重，说明文字不小于 12px，数字使用等宽数字。
6. 布局：保留照片、款式、要求、设置的原顺序，放宽桌面工作区，手机保留双列款式。
7. 细节：减少嵌套边框与卡片，保留键盘焦点、图像放大、原有账户和点数操作。
8. 图片：登录页使用 img2.6 生成的法式美甲工作台场景，款式和结果图片承担工作区的主要视觉。
9. 动效：去掉款式悬停缩放，统一短促的颜色、透明度与位移过渡，尊重减少动画设置。

## 新封面尝试

调用用户配置的 img2.6 服务，模型 `gpt-image-2.6-sunburst`，PNG，3840×2160，质量 `max`。首次请求的图片下载不完整，结束了本地挂起下载，没有自动重发生成请求。

用户更新 skill 并明确要求再试后，于 2026-11-05 使用相同提示词重新提交一张图片，改用 `b64_json` 返回，约 28 秒成功取得完整的 3840×2160 PNG。登录页已采用此图，网页版本为 `web/public/images/nail-studio-cover.webp`，1920×1080，约 90 KiB。图片为生成的美甲场景示意，不是顾客照片或真实店铺案例；页面注明“场景示意”。来源见 `web/public/images/SOURCES.md`。

本次提交的完整提示词：

> 一张真实美甲工作室的商业摄影照片，用作 Nail Note 美甲效果预览工具的登录封面。自然窗光从左上方照进来，一位成年女性的双手自然放在浅灰白色石材美甲桌面上，手指放松、不重叠，完整准确的手部解剖，刚完成的短圆方形细白边法式美甲，半透明淡粉甲床，清晰可见的真实皮肤细纹与甲缘，精致但不过度修饰。手在画面右侧中部，旁边仅有一支打开的裸粉甲油和一小条带有酒红、乳白、鼠尾草绿甲片的色卡。左侧和顶部留出大面积安静的浅灰白桌面，适合网页放置品牌和标题，底部也保持简洁。画面明亮自然、真实可信，质感像独立美甲工作室的作品集实拍，真实镜头、柔和接触阴影，色彩只集中在美甲和色卡上，无夸张景深，不要磨皮，不要塑料质感，不要抽象装饰。横向16:9，3840x2160，无文字、无字母、无logo、无水印、无界面元素。
